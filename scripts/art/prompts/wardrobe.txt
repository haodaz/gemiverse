Write a three.js ES module of wearable parts for a chibi character about 1.1 m tall in a cozy diorama. The character's head is a sphere of radius 0.22 m centred at y = 0.86; the torso is a tapered capsule from y = 0.34 to y = 0.64, about 0.24 m wide at the shoulders; arms hang at x = +-0.15; legs from y = 0 to y = 0.34. Every part is a function (THREE, opts) -> THREE.Group built in the character's own coordinates (origin between the feet), so a caller can just add it to the character group.

Exports:
- export const HAIR = { short, buzz, middlePart, curly, afro, braids, bob, longStraight, ponytail, twinBuns, wolfCut, locs, pixie, sidePart, hijab, turban } (opts = { color, accent }): shaped from several overlapping lathe/sphere/extrude pieces so each reads clearly from a three-quarter view; never a single ball.
- export const TOPS = { hoodie, tee, shirt, cardigan, varsityJacket, sweater, puffer, blazer, overalls, jersey } (opts = { primary, secondary, accent }).
- export const BOTTOMS = { trousers, shorts, skirt, jeans, joggers, pleatedSkirt } (opts = { primary }).
- export const SHOES = { sneakers, boots, loafers, slippers } (opts = { primary, secondary }).
- export const HEADWEAR = { cap, beanie, headphones, bucketHat, beret, flowerCrown, gradCap } (opts = { primary, accent }).
- export const FACE = { roundGlasses, squareGlasses, sunglasses, freckles, blush, mask } (opts = { primary }).
- export const CARRY = { backpack, toteBag, coffeeCup, book, guitarCase, skateboard, camera } (opts = { primary, secondary }).

Rules for the module:
- It is a plain ES module. Do not import anything. Do not use any global: every function receives THREE (three.js r160 namespace) as its first argument and must pass it on to any helper it calls.
- Units are metres. Y is up. Build only from three.js primitives and ExtrudeGeometry/LatheGeometry shapes you make yourself (bevelled extrudes and spheres for soft edges). No textures from files, no fonts, no text, no logos, no network, no document or window.
- Style: a refined, cozy, stylised diorama, like a premium life-sim game. Soft rounded edges everywhere, believable proportions, small secondary details. MeshStandardMaterial with thoughtful roughness/metalness; castShadow and receiveShadow on meshes.
- Every mesh that carries a themable colour must have userData.slot set ("primary", "secondary", "accent", "wood", "metal", "fabric", "skin", "fur", "furAccent").
- Also export const CATALOG: an array of { id, name, kind, footprint: [w, d], placement: "floor" | "wall" | "surface" | "worn" | "pet", variants: number, note } with one entry per thing in the module, so a shop or wardrobe screen can list it.
- Return only the code of the module in one ```js block.
